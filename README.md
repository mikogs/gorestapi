# gorestapi

Package `gorestapi` mounts a ready-made JSON REST API on top of a [gocrud](https://codeberg.org/mikolajgasior/gocrud) service. A single handler covers list, read, create, update, and delete for every route you register — with no code generation and no framework lock-in.

Check the [documentation](https://codeberg.org/mikolajgasior/gorestapi) for more details.
